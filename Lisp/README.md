# Lisp

Short functions from the functional programming labs, in one file.

`VSUM` adds two lists of numbers element by element and keeps the tail of the longer one. `P4` on a tree of type 2, `(A (B) (C (D) (E)))`, rewrites it as type 1, `(A 2 B 0 C 2 D 0 E 0)`, where the number after each node is how many children it has. The second `P4` multiplies every numeric atom in a nested list. `P16` flattens a nested list into one list of atoms, in the same order.

Technologies: Common Lisp.
