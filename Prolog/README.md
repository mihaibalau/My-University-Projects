# Prolog

Three labs, each file is the statement in a comment and the predicates under it.

`Lab2 - P4 - R1.pl` computes the difference of two sets, and inserts `1` after every even element of a list.

`Lab3 - P4 - R2.pl` adds two numbers given as digit lists. On a mixed list such as `[1, [2, 3], 4, [6, 7, 9], ...]` it sums the numbers that are themselves sublists and returns that sum as a digit list. The helpers convert a digit list to a number and back.

`Lab4 - P4 - R3.pl` collects the strictly ascending sublists of a list. The comment above the predicate is the mathematical case split, and the clauses follow that order.

Technologies: Prolog.
